# Mordheim Homebrew BSData

Public repository for Mordheim homebrew catalogues intended for New Recruit testing and distribution. This is community data, not an official BSData release.

## Current pilot

The repository starts with the three files used for the Cursed Cavalcade (Grade 1c) pilot:

- `Mordheim.gst` — game system definitions
- `data.cat` — shared Mordheim entries
- `The Cursed Cavalcade (1c) - Local Pilot Draft.cat` — warband catalogue

Keep these files together when importing them. In New Recruit, add this GitHub repository from **My Systems → Add a game from GitHub**. Choose **Latest changes** to follow updates on the default branch.

## Provenance and reuse

The files retain their in-file source and author references where available. In particular, the pilot catalogue identifies its source document and provenance in a rule entry. These references record provenance; they do not assert ownership or grant a blanket reuse licence. No repository-wide licence is declared.

Before adding another catalogue, record its source and author, check the applicable permission or licence, and keep New Recruit-specific structures intact.
